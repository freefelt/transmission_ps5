Exit Transmission?

Active downloads will be paused and remembered, Transmission (the daemon) will shut down cleanly, then this page will close together with the Transmission.elf manager.

You can start it again by sending Transmission.elf to the console: the paused downloads will resume.

Transmission is closing

Downloads are being paused and the daemon is shutting down. This takes a few seconds; when the page stops responding, everything is closed.

To start it again, send Transmission.elf to the console.

Remove the download folder?

The folder will be removed from the list. The files and torrents in it are not deleted.

When all downloads finish

If all downloads are paused or removed, the action deactivates itself and the console does nothing. The activation is not saved: after sleep, power off or a manager restart it is off. If the console woke up (including when it went to sleep by itself on its own timer), the activation is cleared as well: turn it on again.

Icon on the “Media” tab

Status…
The icon opens this page in the PS5 browser. The app registers a separate short process, transmission_i.elf, with the system (the Payload Manager method): if it hangs, the manager and Transmission are not affected, and there will be no automatic retries. Installation takes a few seconds.

System service…
If Transmission “hangs” after sleep but this page works, press the buttons below and send the result. “Check Transmission” shows whether it accepts a local connection and responds. “Threads”: where the process threads stand (the wait column shows what a thread is waiting for). “Log”: the last lines of shim.log. “Drives”: which of /mnt/ext*, /mnt/usb* are connected (press with the drive and without it). “Mount points”: all mount points the manager sees (USB and M.2 first).
